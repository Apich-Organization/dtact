## 2024-05-19 - [Hoisting invariant exact queue indices calculations across functions to eliminate redundant atomics]
**Learning:** In hot Rust code paths, especially SPSC/MPMC queues in this project, the compiler cannot optimize away redundant atomic loads of thread-local pointers (even with `Ordering::Relaxed`) across helper functions. For instance, when pushing batches into an SPSC queue in `route_local`, calculating exact offsets from `cur_len` and `fixed_head` avoids reloading the queue tail length with atomics.
**Action:** When working on very hot loops interacting with thread local atomic state, identify immutable state or deterministically updating state from that thread, compute it mathematically, and pass the explicit state values into inner functions to bypass reloading thread local atomics.
