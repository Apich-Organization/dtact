## 2024-05-18 - Atomic Load Reduction in Hot Loops
**Learning:** In the core dispatch and routing loops (`Worker::push_local`, `route_chunk`, `drain_warehouse`), redundant atomic loads of queue pointers (`local_head` and `local_tail`) caused unnecessary overhead, as calculating the queue length requires both values but the length was often recalculated or values were re-read. When operating on the local queue thread, `local_head` is immutable and can be cached.
**Action:** Always examine chained function calls in hot loops for redundant state checks. Pass pre-calculated states (like queue length) or cache immutable pointers (like `local_head` on the consumer thread) to minimize atomic operations in performance-critical sections. Note that when caching dynamically updated bounds within a loop, one must ensure to check dynamic values per iteration if they are modified.
