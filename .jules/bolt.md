## 2023-10-24 - Avoid indirect calls in manual "branchless" arrays
**Learning:** Using an array of function pointers (e.g., `const ROUTES: [RouteFn; 4] = [...]; ROUTES[idx](...)`) to avoid branches in Rust is a severe anti-pattern. While it removes an `if` statement in source code, it prevents the compiler from inlining the target functions (despite `#[inline(always)]`), forcing a dynamic indirect jump (`jmpq *%reg`) at runtime. This adds indirect branch misprediction overhead and ruins hot-path inlining. A standard `if/else` or `match` allows LLVM to fully inline the functions and natively generate true branchless instructions (like `cmov`) or well-predicted direct branches.
**Action:** Replace hot-path manual function pointer arrays with standard `if`/`else` or `match` blocks.
