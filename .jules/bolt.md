## 2024-05-24 - Manually Hosting Atomic Loads in Rust SPSC/MPMC Queues
**Learning:** In hot Rust code paths, particularly when managing SPSC/MPMC queues, LLVM struggles to optimize away redundant atomic loads (e.g. `Ordering::Relaxed` reads of `local_tail`) across helper function boundaries, even when logically redundant and computationally determinable. This leads to unnecessary cache/bus traffic that degrades high-frequency loop performance.
**Action:** Always manually hoist immutable or deterministically mutating atomic variables (like queue heads or tails) in the parent loop. Use mathematical derivations (e.g., `(head + len) & MASK`) to compute accurate pointer indices locally, and pass these pre-calculated states explicitly into downstream helper functions (e.g., passing the computed `tail` offset directly to `push_batch`). Ensure helpers return delta changes when mutating state to allow accurate local tracking across loop iterations without repeated atomic polling.
