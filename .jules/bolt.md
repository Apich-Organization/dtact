## 2024-05-24 - [Hoisting Atomic Loads in SPSC Queues]
**Learning:** In high-frequency scheduling loops involving SPSC/MPMC queues (like `drain_warehouse` or `poll_mailboxes`), thread-local variables such as the queue head (`local_head`) are immutable throughout the loop. The tail position (`local_tail`) can be mathematically derived from loop invariants (`fixed_head` + `cur_len` `&` mask). By hoisting the immutable load outside the loop and calculating the exact tail position to pass into helper functions (`push_batch`), redundant and expensive atomic loads (`AtomicUsize::load(Ordering::Relaxed)`) across helper function boundaries are eliminated.
**Action:** When working on performance-critical loops with SPSC/MPMC queues, carefully trace which thread mutates the state. Hoist immutable loads (like `head`) out of the loop and manually track state changes (like `tail` offset) via math instead of relying on redundant inner-loop atomic loads.
